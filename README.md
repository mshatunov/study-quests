# Study Quests

Interactive revision quizzes, one page per test, each with its own look.
Homepage: https://mshatunov.github.io/study-quests/

```
index.html            homepage (generated by tools/sq.py build from tests.json)
tests.json            registry: one entry per test (subject, theme, date, question count)
assets/engine.js|css  shared quiz engine (15 question types, game modes, mistake bank, glossary, self-test)
themes/*.css          one look per theme; themes/themes.json is the catalog
tests/<id>/data.js    the questions of one test (the only file written by hand)
tools/sq.py           themes | new | check | build | publish
tools/lint.js         fast data check without Chrome: node tools/lint.js <id>
```

Progress lives in the browser (localStorage): `sq:<test id>` - XP, best scores, mistake bank, records, badges,
unfinished round (saved after every answer); `sq:profile` - daily streak; `sq:ui` - glossary open/closed.

Workflow lives in the `study-quests` skill of the ai-pkm repo (portable/skills/study-quests/SKILL.md).
